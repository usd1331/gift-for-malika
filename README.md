# Подарок для Малики

Интерактивная открытка: вопрос «Хочешь кое-что?», экран засыпает цветами,
появляется букет в стеклянной вазе, котик выходит из-за вазы с конвертом,
конверт открывается, и письмо прямо на глазах пишется от руки на листке в клетку.

## Как открыть
Открой `index.html` в браузере (двойной клик). Сервер не нужен.
Рукописный шрифт (Marck Script) и остальные шрифты грузятся из Google Fonts,
поэтому для красивого почерка нужен интернет.

## Файлы
- `index.html` — разметка: экран с вопросом, экран «Нет», сцена с подарком, конверт и текст письма.
- `style.css` — оформление и CSS-анимации (кнопки, конверт, листок в клетку, появление слов).
- `script.js` — логика и рисование на canvas:
  - `flowerStorm()` — цветы засыпают весь экран после «Да»;
  - `PAINT` и `flowerSprite()` — процедурные цветы;
  - `paintBackground()` — стена и деревянный стол;
  - `planBouquet()` / `drawBouquet()` — букет и стеклянная ваза с водой;
  - `drawWalkingCat()` — шагающий пушистый котик;
  - `frame()` — таймлайн сцены;
  - `openLetter()` — анимация конверта;
  - `prepHandwriting()` / `writeLetter()` — каждое слово чуть по-своему наклонено и смещено, как в живом почерке, и слова пишутся по очереди. Нажатие на письмо дописывает его сразу.
- `assets/cat.webp` — котик без фона, `assets/cat.png` — то же в PNG, `assets/cat-original.png` — исходник.

## Что легко поменять
- Текст письма: абзацы `<p>` внутри `<div class="page" id="page">` в `index.html`.
- Скорость письма: в `writeLetter()` число `70` (миллисекунд на букву).
- Почерк: шрифт задан в `.page { font-family: "Marck Script" ... }` в `style.css`.
