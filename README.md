# Подарок для Малики

Интерактивная открытка: вопрос «Хочешь кое-что?», экран засыпает цветами,
появляется букет в стеклянной вазе, котик выходит из-за вазы с конвертом,
конверт открывается, и внутри письмо, написанное от руки.

## Как открыть
Открой `index.html` в браузере (двойной клик). Сервер не нужен.
Шрифты грузятся из Google Fonts, без интернета будет запасной шрифт.

## Файлы
- `index.html` — разметка: экран с вопросом, экран «Нет», сцена с подарком, конверт и письмо.
- `style.css` — оформление и CSS-анимации (кнопки, конверт, письмо, увеличение письма).
- `script.js` — логика и рисование на canvas:
  - `flowerStorm()` — цветы засыпают весь экран после «Да»;
  - `PAINT` и `flowerSprite()` — процедурные цветы;
  - `paintBackground()` — стена и деревянный стол;
  - `planBouquet()` / `drawBouquet()` — букет и стеклянная ваза с водой;
  - `drawWalkingCat()` — шагающий пушистый котик;
  - `frame()` — таймлайн сцены;
  - `openLetter()` — анимация конверта и письма; клик по письму увеличивает его.
- `assets/letter.webp` — письмо от руки (очищенный скан), `assets/letter-original.jpg` — исходное фото.
- `assets/cat.webp` — котик без фона, `assets/cat.png` — то же в PNG, `assets/cat-original.png` — исходник.

## Что легко поменять
- Письмо: замени `assets/letter.webp` своей картинкой.
- Подпись «Твой Р ❤️»: `<figcaption class="sign">` в `index.html`.
- Тексты вопроса и экрана «Нет»: секции `#ask` и `#nope` в `index.html`.
